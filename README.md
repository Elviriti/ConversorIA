# 🌡️ Conversor de Unidades IA

Este proyecto es una aplicación sencilla en Java diseñada para convertir unidades de medida, desarrollada con el apoyo de **Inteligencia Artificial** y gestionada mediante **Git**.

## 🚀 Características
- Conversión de Kilómetros a Millas.
- Conversión de Millas a Kilómetros (añadido en la rama `feature-update`).
- Código limpio y documentado.

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** Java
- **IDE:** IntelliJ IDEA
- **Control de Versiones:** Git & GitHub
- **IA Colaboradora:** Gemini / ChatGPT

## 📈 Flujo de Git realizado
1. `git init` - Inicialización del proyecto.
2. `git branch` - Creación de rama para nuevas funciones.
3. `git merge` - Integración de mejoras en la rama principal.
4. `git push` - Despliegue en el repositorio remoto.
